# Jsonable

一个在浏览器本地识别、预览并批量修改 JSON/Lottie 颜色、组合形状、图片资源与缓动曲线的可视化编辑器。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，例如 `jsonicle`。
2. 将本项目推送到仓库的 `main` 分支。
3. 打开仓库的 **Settings → Pages**，将 **Source** 设为 **GitHub Actions**。
4. 等待仓库中的 **Deploy to GitHub Pages** 工作流完成。

完成后，网站地址通常是 `https://你的用户名.github.io/jsonicle/`。

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```
